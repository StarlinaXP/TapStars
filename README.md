TapStars Installation Guide (iOS)

OS Support
Android
iOS

For iOS Users

Requirements:
Operating System: Windows or macOS

Installation Instructions:

Download Sideloadly
Visit sideloadly.io
 and download the version compatible with your system.
(You may use another sideloading tool if preferred.)

Run Sideloadly

On macOS, if the system flags Sideloadly as malware, go to System Settings → Privacy & Security, and select Allow Anyway to open it.

On Windows 10, you can follow this video tutorial for detailed instructions: https://youtu.be/vqTsavQc3lQ

(Windows and MacOS)
Sign In with Your Apple ID
Log in with your Apple ID within Sideloadly to sign the TapStars app.
(Your credentials are only used to create a signing certificate and are safe.)

Enable Developer Mode
Make sure Developer Mode is enabled on your iOS device.

Install and Trust the App

Once installation is complete, go to Settings → General → VPN & Device Management.

Tap Trust [Your Apple ID] under the developer profile.

Launch TapStars
You can now play TapStars on your iOS device!

Note: Free Apple developer certificates expire every 7 days. When this happens, simply repeat the signing and installation process to continue playing.
